# Добавяне и публикуване на съдържание

1. Отвори публикувания `admin.html` през GitHub Pages.
2. Въведи паролата за редактора при всяко отваряне на страницата, за да добавяш и редактираш статии или членове на екипа.
3. За статия попълни заглавие, рубрика, дата, описание и текст. Можеш да добавиш водеща снимка до 700 KB и надпис; снимката се показва над текста на статията.
4. За архив избери „Резервно копие JSON“.
5. Създай GitHub Fine-grained personal access token само за `itzVexlen/proekt-po-bel` с разрешение `Contents: Read and write`. Постави го в редактора и избери „Свържи и зареди“. При всяко запазване или изтриване админът качва отделен JSON файл в `js/content/posts/` или `js/content/team/` и обновява съответния `index.json` в GitHub с commit. Съдържанието се зарежда от тези JSON файлове на всички устройства.

Token-ът се изпраща директно към GitHub и остава само в паметта на отворения admin таб. Въведи го отново на всяко устройство/нова сесия; не споделяй token-а и отнеми достъпа му, ако стане достъпен на други хора. Паролата на редактора е записана в JavaScript кода и служи само като базова заключалка; тя не защитава съдържанието от технически достъп.

Налични рубрики: `sport` (Спорт), `science` (Наука и открития), `young-scientists` (Младите учени), `school-life` (Училищен живот), `achievements` (Нашите успехи), `creative` (Творчески път).
